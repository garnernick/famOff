# EA Portal demo

Clickable demo of the VoleAlti EA/PA portal. Draft with sample content: names, prices, times and links are placeholders.

Open `index.html` (it redirects to `Main.dc.html`). No build step or server is needed. Plain static files, so it can be served as-is, for example with GitHub Pages.

Pages: Main (welcome), SignIn, Home (search, quotes, trips), Calendar, Account (includes Referrals), Confirmation.

Fonts (Cinzel, Jost) load from Google Fonts.
